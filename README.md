# Escape-From-Thuldor
Game 2 of the 20 Games Challenge. A Jetpack Joyride remake made using Godot!

Project is currently playable as a web game on my Itch.io page:
https://morpeth-jetsan.itch.io/escape-from-thuldor

In total the project took about 8 days, with a few hours each day. This involved the coding, the art, and the sound design.
